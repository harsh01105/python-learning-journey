# 02 - if-else and Flow Control

**Book chapter:** Automate the Boring Stuff with Python, 3rd Ed. — Chapter 2

## Notes
- Booleans: `True` / `False` — the result of any comparison.
- Comparison operators: `== != < > <= >=`
- Boolean operators: `and`, `or`, `not` — combine multiple conditions.
- `if` runs a block only when its condition is `True`.
- `elif` checks another condition if the previous one was `False`.
- `else` runs when none of the above conditions matched.
- Conditions are checked top to bottom — only the first matching block runs.
