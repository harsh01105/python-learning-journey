# Python Learning Journey

MCA student's daily Python learning log - from fundamentals to intermediate,
building toward a small portfolio of automation projects.

## Resources
1. **Automate the Boring Stuff with Python, 3rd Edition** - Al Sweigart (free at automatetheboringstuff.com/3e)
2. **freeCodeCamp - Python for Beginners (Full Course)** - freecodecamp.org / YouTube

## How this repo is organized
- `01-python-basics/` ... `14-sqlite-databases/` - one folder per topic, in study order.
  Each contains a README with notes and 1-2 exercises + solutions, added day by day.
- `projects/` - three portfolio projects built after finishing the core topics.
