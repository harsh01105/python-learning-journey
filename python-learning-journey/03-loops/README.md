# 03 - Loops

**Book chapter:** Automate the Boring Stuff with Python, 3rd Ed. — Chapter 3

## Notes
- `while` loop: repeats a block as long as a condition is `True`.
- `for` loop: repeats a block a set number of times, usually with `range()`.
- `range(start, stop, step)` — `stop` is excluded.
- `break` exits the loop immediately.
- `continue` skips the rest of the current iteration and moves to the next one.
- Watch out for infinite loops — always make sure the condition can eventually become `False`.
